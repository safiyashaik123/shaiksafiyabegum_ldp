# Git Attributes Kata

## Objective
Learn how to use .gitattributes to control file handling, line endings, and encoding in Git.

## Commands Used

git add
- Staged files and applied .gitattributes rules.

git status
- Checked repository status.

git commit
- Saved changes to repository history.

git log --oneline
- Verified commit history.

## New Concepts Learned

.gitattributes
- Controls how Git handles different file types.

eol=lf
- Forces Linux/Mac line endings.

eol=crlf
- Forces Windows line endings.

working-tree-encoding=UTF-8
- Uses UTF-8 character encoding.

diff=useexif
- Enables image metadata comparison.

## Summary

Learned how to use .gitattributes to manage line endings, encoding, and file handling behavior in Git repositories.
