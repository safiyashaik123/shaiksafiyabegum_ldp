# Merge Driver Kata

## Purpose
To learn how to configure a custom merge driver and automatically resolve merge conflicts.

## What I Did

1. Ran the setup script and entered the exercise repository.
2. Configured a custom merge driver in .git/config.
3. Configured .gitattributes to use the merge driver for .tst files.
4. Merged the feature/1 branch into master.
5. Verified that the conflict was resolved automatically.

## Learning

- Merge drivers automate conflict resolution.
- .git/config registers merge drivers.
- .gitattributes maps file types to merge drivers.
